# UI and update-sound follow-up 0.2.171

The added global Ready/footer strip is removed from every screen. It previously painted a gray rectangle after both the Home screen and launcher and covered the existing battery area. An unchanged scene held on the TFT during a TLS framebuffer loan now receives no writes, including no animated HTTP marker. Inputs and scene changes still redraw; restoring the sprite resumes normal rendering. Remaining physical flashing must be checked on the device separately.

The existing Home READY / BUILDING / NEW UPDATE badge now shows remaining `mm:ss` while Pomodoro is running. A short/long break or reflection shows BREAK. Paused and stopped phases restore the current firmware badge, including BUILDING. Voice preparation and the physical G0 indication retain their priority. No new global status row is introduced. The warm badge accent is RGB(255,136,64), an orange selected against the cyan/dark-blue palette and previewed after RGB332 quantization; breaks remain green and idle clock digits remain white.

The app entry Focus Space is renamed Pomodoro. Its settings use the same name. Standalone Clock and Battery launcher entries are removed from System; the clock and charge indicators remain on Home. Existing mode IDs and command compatibility are retained.

Firmware notifications use a quiet pair of damped, low wooden taps instead of the old chord/high inbox alert. The PCM buffer is the same 1,920 samples at 8 kHz (240 ms, 3,840 bytes); its measured peak is 1,469/32,768. It does not change the user's speaker-volume setting, respects the update-sound toggle and yields to recording, playback, Realtime and setup of their transports. OTA-release and firmware-job notices use this sound; ordinary chat replies keep their existing notification. Device acoustics require owner listening. The sound used to announce this release before installation is still controlled by the already installed firmware.

This release also contains the prepared EN-only audio-pack compatibility change. English is the bundled default; optional existing Russian cues are preserved. Missing optional languages do not make a complete English pack fail readiness. Missing enabled cues can synchronize from SD's authenticated asset manifest on future firmware versions as well, rather than being tied to version 0.2.170.

Validation includes the actual badge renderer and bounds, active/pause/break priorities over firmware states, no stray writes during a held frame, visible battery geometry, actual inbox sound selection, audio ownership and opt-out, chime envelope/peak/gap checks, existing firmware regressions and an ESP32-S3/8 MB compile. A host pass or published OTA file does not establish absence of visible flashing, native BUILDING delivery, or physical speaker acceptance.
