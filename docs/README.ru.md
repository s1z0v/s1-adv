# S1-ADV для Cardputer ADV

S1-ADV: карманная прошивка для твоего OpenClaw, клавиатура, микрофон, динамик и экран.
Агент работает на компьютере или сервере. На Cardputer работает клиент и
локальные приложения: таймер фокуса, заметки, калькулятор, часы, игры и питомец.

Нужны **M5Stack Cardputer ADV**, USB-кабель с передачей данных, Wi-Fi 2.4 ГГц,
Python/PlatformIO для прошивки, работающий OpenClaw и Node.js 22+ для моста.
Для голоса отдельно нужны FFmpeg, распознавание и синтез речи на сервере.

1. Клонируй `https://github.com/srg0/s1-adv`.
2. Настрой [мост к своему OpenClaw](OPENCLAW.md). Пример не содержит личных тем
   Telegram. Создай свой токен устройства в приватном локальном файле.
3. Собери и залей [прошивку](FLASHING.md) через `scripts/cardputer.py`.
   Цель: **ESP32-S3, 8 MB flash**, таблица разделов из репозитория.
4. Проверь один текстовый вопрос и ответ на экране, затем обычное голосовое
   сообщение. Экспериментальный realtime включай отдельно.

В [инструкции](OPENCLAW.md#give-this-to-your-openclaw-agent) есть готовый промпт
для установки с помощью твоего OpenClaw. Интеграция состоит из отдельного
сервиса `bridge/` и необязательного навыка `skills/s1-adv/`.
Навык сам по себе сервер не устанавливает.

Если порт не появился: зажми G0, нажми Reset, отпусти G0 и повтори загрузку.
Не заливай app-образ `firmware.bin` с адреса `0x0`: это адрес только для
специально собранного merged/full-образа.

Проект экспериментальный. Публичная конфигурация ещё требует проверки на
чистом физическом устройстве. Не публикуй `.env`, токены, логи личных разговоров
и прошивки, в которые уже встроены твои Wi-Fi-пароль и токен.
