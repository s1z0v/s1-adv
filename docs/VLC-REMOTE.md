# VLC Remote — локальный пульт для Mac

## Для уже настроенного личного устройства

В приватную сборку включены настройки ранее настроенного VLC. Пароль на
Cardputer вводить не нужно, повторно настраивать Mac тоже не требуется.
Старые настройки/NVS устройства не требуют сброса или стирания.

1. Установите опубликованное OTA-обновление **0.2.202-dev** обычным способом.
   Публикация сама по себе не подтверждает установку.
2. Оставьте **VLC запущенным на Mac**, откройте файл, поток или плейлист.
3. Подключите Mac и Cardputer к одной доверенной локальной сети.
4. На Cardputer: **Tab → Media → VLC Remote → Enter**.
5. Пульт сам проверит соединение и покажет состояние VLC, название текущего
   материала, позицию и громкость. Открытие пульта **не запускает** воспроизведение.

Mac-сторона (VLC 3.0.24, HTTP API, авторизация с пустым именем пользователя и
Bonjour-регистрация) ранее проверена владельцем отдельно. Проверка этого
обновления на физическом Cardputer после установки остаётся отдельным шагом.

## Кнопки

| Кнопка | Действие |
| --- | --- |
| Enter / Space | Воспроизвести / пауза |
| X | Стоп |
| N / P | Следующий / предыдущий элемент плейлиста |
| W / S или ↑ / ↓ | Громкость VLC примерно ±5 процентных пунктов |
| + / − | То же изменение громкости |
| A / D или ← / → | Перемотка −10 / +10 секунд |
| R | Заново найти Mac и проверить соединение |
| Tab | Меню приложений |
| Esc | Выйти из пульта; VLC продолжает играть на Mac |

Это **пульт**, не передача аудио на Cardputer: звук остаётся на выбранном
аудиовыходе Mac, в том числе на подключённых к Mac AirPods/колонках.
Переключение треков работает по плейлисту VLC. Перемотка доступна только для
материала, который сам VLC позволяет перематывать; у живого радио её может не быть.

## Автоподключение

Порядок получения адреса и безопасной проверки статуса:

1. Bonjour/mDNS: сервис **`_vlc-http._tcp`**. Берутся адрес и порт только сервиса,
   чей hostname соответствует приватно заданному имени Mac.
2. Если сервис не найден/недоступен — разрешение заданного имени **`.local`**.
3. Если имя недоступно — приватно заданный резервный LAN IPv4 и порт.

На экране виден использованный маршрут: `Bonjour`, `Hostname` или `LAN fallback`.
Разрешены только приватные IPv4 в текущей подсети Cardputer; отсутствуют сканирование
всей сети, доступ к произвольным публичным адресам и переходы по HTTP-редиректам.
При смене сети/адреса нажмите **R**. Bonjour помогает пережить смену DHCP-адреса Mac;
резервный IP предназначен для последнего случая, а не заменяет обнаружение.

После успешного подключения статус опрашивается раз в три секунды, только пока
открыт пульт и свободны сетевые/аудиоресурсы устройства. При ошибке автоматические
попытки прекращаются до R. Управляющие запросы **не повторяются автоматически**,
не ставятся в очередь и не пересылаются на резервный адрес при тайм-ауте:
иначе play/pause или next могли бы выполниться дважды.

## Ошибки и завершение проверки

- **Wi-Fi required** — сначала подключите Cardputer к сети Mac.
- **Mac not found / VLC unavailable** — VLC должен работать; оба устройства
  должны быть в одной сети без изоляции клиентов/guest Wi-Fi. Проверьте, что
  локальный HTTP-интерфейс VLC и сохранённая Bonjour-регистрация на Mac запущены.
- **HTTP 401** — VLC отверг сохранённый пароль. Нужна коррекция приватной
  конфигурации, а не отправка пароля в чат. Имя пользователя остаётся пустым.
- **Timeout** — результат последней команды неизвестен: сначала **R**, проверьте
  статус и только после этого при необходимости повторите команду вручную.
- **Busy** — запрос не отправлен и не поставлен в очередь; закончите текущую
  операцию и повторите нажатие. Запись голоса/Realtime/OTA и другие владельцы
  ресурсов не запускаются поверх сетевого запроса VLC.

Приёмка на устройстве: увидеть корректный статус, проверить pause/resume, X,
N/P на плейлисте, громкость, перемотку на обычном файле и выход Esc без остановки
Mac. Затем убедиться, что обычный чат, запись голоса и OTA продолжают работать.
Для проверки отказов: выключить VLC/изменить доступность сети, получить ошибку,
вернуть VLC и нажать R. Наличие корректного пароля на Mac само по себе не доказывает
работу mDNS/кнопок с физического Cardputer.

## Приватность сборки

Публичный исходный код **не содержит** личных адресов или паролей. Приватный
build wrapper передаёт только путь к локальному файлу настройки. Pre-script
проверяет права файла и формирует приватный заголовок в игнорируемом `.pio`;
пароль не попадает в `-D`/командную строку компилятора, Git или release notes.
Без этого локального файла обычная публичная сборка показывает
`VLC not provisioned`, не пытаясь подключаться.

Личные defaults используются, если отдельная VLC-конфигурация в NVS ещё не
существует, не помечена как настроенная или невалидна. Они не перезаписывают
Wi-Fi, provisioning устройства, настройки других приложений или SD-карту.

HTTP Basic Auth в этом режиме **не зашифрован**. Используйте отдельный пароль VLC
и только доверенную LAN; не публикуйте порт в интернет и не отключайте firewall.
Приватный OTA-бинарник содержит личные defaults: его нельзя прикладывать к
публичным GitHub Releases. Обычный bridge/OTA сохраняет свои TLS и проверки.

Документированный API VideoLAN:
https://github.com/videolan/vlc/blob/3.0.x/share/lua/http/requests/README.txt
